📝 Descrição
O AMT Solutions é um sistema de Gestão de Recursos Empresariais (ERP) desenvolvido para integrar e gerenciar processos de negócios essenciais. O software foi projetado para centralizar operações de vendas, estoque, financeiro e gestão de negócios em uma única interface intuitiva.
+1

🛠️ Tecnologias e Ferramentas

Backend: PHP para tratativa de dados e criação de APIs com endpoints REST (retorno em JSON).


Frontend: HTML5 e CSS3 para interface customizada , com JavaScript para manipulação do DOM e integração com o Backend.

Banco de Dados: MySQL para armazenamento e proteção dos dados.

Servidor: Ambiente simulado via XAMPP.

Prototipação: Desenvolvido inicialmente no Figma.

Versionamento: Git e GitHub.

⚙️ Funcionalidades Principais

Módulo de Vendas: Gerenciamento de pedidos e histórico de transações.

Gestão de Estoque: Controle de entrada e saída de produtos.

Financeiro: Monitoramento de fluxo de caixa e contas.

Módulo Gestor: Painel administrativo para tomada de decisão baseada em dados.

👥 Metodologia de Desenvolvimento
O projeto foi conduzido sob a metodologia ágil Scrum.

Gestão de Sprints: Utilização do Trello e MIRO para acompanhamento de features e progresso das Sprints.

Arquitetura: Sistema modular para facilitar a manutenção e escalabilidade dos processos.

🚀 Como Executar o Projeto
Certifique-se de ter o XAMPP instalado.


Clone este repositório:
git clone https://github.com/tallesdecosta/amt-solutions.git


Mova a pasta do projeto para o diretório htdocs do seu servidor local.

Importe o arquivo .sql (se disponível) para o seu banco de dados MySQL.

Acesse localhost/AMT-Solutions no seu navegador.
